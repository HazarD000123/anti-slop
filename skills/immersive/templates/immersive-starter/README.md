# Immersive starter

A working scroll-driven WebGL world to replace with your own: terrain, a glass hero, particles that morph between shapes, a post stack, transitions, sound toggle, quality tiers and accessible HTML.

```bash
npm install
npm run dev
```

Start in `src/main.js`, at the timeline under "the journey". Storyboard your camera path there first.

Replace, in this order: the world (terrain), the hero model, the particle shapes, the copy in `index.html`, the sound. Keep the bones. Asset compression is covered in the skill's `references/assets.md`.
